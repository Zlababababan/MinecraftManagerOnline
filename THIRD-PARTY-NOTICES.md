## Downloaded at run time, not bundled

### Java runtimes

The agent installs a JRE by itself when a server needs one, from official sources, and the panel can
relay and cache those downloads for machines without direct Internet access:

- **Eclipse Temurin** (Adoptium) — GNU General Public License v2 with the Classpath Exception.
  <https://adoptium.net/docs/faq/>
- **Azul Zulu** — GNU General Public License v2 with the Classpath Exception, used as a fallback
  where Temurin publishes no build. <https://www.azul.com/products/core/>

These runtimes are never modified, and never redistributed inside our archives.
