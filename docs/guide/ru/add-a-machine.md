# Добавление машины

[English](../add-a-machine.md) · [Français](../fr/ajouter-une-machine.md) · [Español](../es/add-a-machine.md) · [Deutsch](../de/add-a-machine.md) · [Português](../pt/add-a-machine.md) · **Русский** · [中文](../zh/add-a-machine.md)

_Перевод английской версии, которая является эталонной. Интерфейс приложения доступен на английском и французском языках._

**Машина** — это компьютер, на котором размещены серверы Minecraft и которым управляет агент. Хост панели тоже может быть машиной (самый частый случай: всё работает на одном игровом ПК).

## 1. Создание машины и получение команды

1. Панель → **Machines** → **Add a machine** (добавить машину), задайте имя.
2. Панель показывает **код сопряжения** (`MMOP-XXXX-XXXX`, действителен 15 минут, одноразовый) и полную команду для Windows и для Linux/macOS.
3. Вставьте команду на целевой машине — подробнее о том, что она делает: [Установка § 2](installation.md#2-агенты).
4. Машина переходит в состояние `online` в панели. Если код истёк, кнопка **New pairing code** (новый код сопряжения) генерирует другой (прежние коды этой машины аннулируются); выполните команду ещё раз.

Команда содержит публичный URL панели: проверьте его (Settings → General), если целевая машина находится не в той же сети, что и вы.

## 2. Обнаружение серверов

На странице машины: **Watched directories** (отслеживаемые каталоги) → добавьте родительскую папку ваших серверов (например, `E:\Minecraft\Server`, `/srv/minecraft`). Агент сканирует её (Forge, NeoForge, Fabric, Vanilla; 1.12 → 1.21+) и **автоматически принимает под управление** каждый обнаруженный сервер вместе с его loader'ом, версией и объёмом RAM — периодическое сканирование выполняется само по себе, кнопка **Scan now** (сканировать сейчас) запускает немедленный проход, а **Add a server folder** (добавить папку сервера) регистрирует конкретную папку, не дожидаясь сканирования. Всё это можно потом изменить на странице сервера (доработанные вручную сборки иногда обманывают эвристику — для каждого определённого значения показан его источник). В момент принятия под управление на диске ничего не изменяется, за исключением включения RCON (`server.properties`, сгенерированный пароль) — он необходим для управления сервером в detached-режиме.

Java: агент проводит инвентаризацию имеющихся JRE; если нужной версии нет, установите её из карточки **Java runtimes** на странице машины (кнопка **Install this runtime** — Temurin, иначе Zulu; скачивается и проверяется автоматически).

## 3. Первый запуск сервера

Запустите сервер из его карточки (на дашборде) или с его страницы и наблюдайте, как состояние меняется `starting` → `running` (отображается PID). Вкладка **Console** (консоль) показывает строки журнала в реальном времени и принимает команды. Если при первом запуске нового сервера лицензионное соглашение Mojang (EULA) ещё не принято, панель проведёт вас через этот шаг (объяснение, ссылка, флажок), после чего запустите сервер снова. Всё остальное находится во вкладках страницы сервера: **Players** (игроки: whitelist, операторы, баны — и никаких файлов открывать не нужно), **Configuration** (`server.properties` с пояснением каждого поля), **Files**, **Backups**, **Metrics**, **Scheduler**, **Logs**.

## 4. Адреса для игроков

У каждого сервера есть настройка **Exposure** (способ публикации; карточка **Player access**, вкладка Overview страницы сервера):

- **Tailnet**: друзья устанавливают Tailscale и присоединяются к вашему tailnet (общий доступ к узлу или приглашение); адрес, который нужно им дать, — IP машины `100.x.y.z` (или имя MagicDNS) + порт.
- **Direct**: публичный адрес — ваш домен, если машина является хостом панели в режиме direct, иначе глобальный IPv6-адрес машины (или публичный хост, указанный на странице машины в карточке "Addresses for players"). Откройте порт сервера (IPv6-pinhole на роутере + правило, показанное в Settings → Remote access → Firewall rules).

Игрокам в той же локальной сети ничего не нужно: LAN-адрес + порт при любом режиме. Кнопка **Test reachability** на карточке выполняет настоящий _Server List Ping_ с хоста панели (версия, игроки, MOTD): именно это увидит клиент Minecraft.

## 5. Несколько машин

- Серверы можно **мигрировать** с одной машины на другую (карточка **Migration** на вкладке Overview → **Migrate to another machine**): предварительные проверки на целевой машине (место на диске, Java, порт), прямая передача от агента к агенту или ретрансляция через панель, переключение — а старая папка переименовывается в `.migrated-<date>`.
- У **резервных копий** назначение задаётся для каждого сервера (локальная папка либо общая/смонтированная), ротация по политике, восстановление в один клик.
- Обновления агентов: Settings → General → "Update agents automatically when they connect", либо вручную со страницы машины (карточка Agent). Агент, не вернувшийся в работоспособное состояние за 30 с, самостоятельно откатывается на предыдущую версию.

## 6. Удаление машины

Страница машины → **Remove machine** (удалить машину): она исчезает из панели (серверы и файлы остаются на диске нетронутыми). На самой машине: `install.ps1 -Uninstall` / `install.sh --uninstall` ([Установка § 2](installation.md#2-агенты)).
